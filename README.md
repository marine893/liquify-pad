# Liquify Pad

아이패드 + Apple Pencil용 사진 보정 웹앱. 홈 화면에 추가하면 오프라인에서도 동작합니다.

- 보정: 노출·밝기·대비·하이라이트·그림자·흰색/검정 계열, 색온도·색조·생동감·채도, RGB 커브, 흑백 채널 믹스, 화이트/블랙 미스트, 샤프니스, 그레인, 비네트, 히스토그램
- 마스크: 브러시·선형·방사형 부분 보정 (최대 8개)
- 자르기: 비율 고정, 수평 회전, 90° 회전, 뒤집기, 렌즈 왜곡 보정
- 유동화: 포토샵과 같은 단축키(W R E C S B F D)
- 프리셋 저장·공유, 작업 자동 저장·복원, 원본 해상도 JPEG/PNG 내보내기
